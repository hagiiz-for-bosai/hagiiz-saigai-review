# 全国防災団体マップ 公開用データ v1（大学の学生団体）

- 作成日：2026-11-23
- 作成：全国防災団体マップ（収集）のチャット
- 範囲：全国の大学・短期大学・高等専門学校（文部科学省 学校コード一覧、2026-05-20更新、1,175校）に関係する、防災に関わる学生が主体の団体
- 集め方：Gemini Deep Research（標準：全校／高：大規模校41校）、パイロットでのAPI検索、手作業の確認。手順は `COLLECTION_PROTOCOL.md`

## 列の意味
**organizations.csv**
| 列 | 意味 |
|---|---|
| org_type | 大学の学生団体／複数校の連合組織 |
| drr_role | 防災の位置づけ：主目的／活動の一部／関連（献血・防犯など） |
| latest_activity_year | 根拠ページで確認できた最新の活動の年。大規模校の調査でしか集めておらず、多くは空欄 |
| activity_state | 活動中（最新の活動の年が2年以内）／休眠の可能性／不明（最新の活動の年なし） |
| evidence_url, evidence_type | 根拠URLとその種類（学校／PDF／行政／SNS／団体サイト など） |
| checked_date | 確認日（調査の文書の最終更新日） |
| method | 調べ方（DeepResearch_standard／DeepResearch_high／手作業） |

**schools.csv**
| 列 | 意味 |
|---|---|
| lgcode | 学校の所在地の市区町村コード（政令市は区のコード） |
| lgcode_city | 市のコード（地域ページの結合用） |
| lat, lng | 学校の座標。文部科学省「学校コード一覧」の所在地（**本部の所在地**。主なキャンパスと違う場合がある）を、国土地理院の住所検索APIで緯度経度にしたもの |
| coord_precision | 座標の細かさ。「学校の住所（番地）」「学校の住所（町名）」、または「要確認（…）」。要確認の学校は、市区町村役所の位置（仮）のまま |
| geocode_match | 住所検索で一致した住所（確認用） |
| status | has_orgs（団体あり）／none_found_web_2026-11（2026年11月時点でWebで確認できる団体なし） |
| n_orgs, n_orgs_drr | 団体数と、そのうち防災が主目的・活動の一部の数 |

## 表示のときの注意（必ず画面に出すもの）
1. **Webで確認できた団体のみ**です。Webに情報を出していない団体は含まれません
2. 「団体なし」は「2026年11月時点で、Webで確認できなかった」という意味です。存在しないという意味ではありません
3. 活動の状態が「不明」の団体が多くあります（詳細の調査は今後）
4. 団体の拠点は、学校の所在地から推定しています。実際の活動の場所は学校の外のことが多いです
5. 載っていない団体・誤り・掲載の取り下げは、1つの窓口で受け付けます
6. 出典：文部科学省「学校コード」、市区町村コードと役所の位置は Code for FUKUI「localgovjp」（**公開前に総務省の全国地方公共団体コードと照合し、利用条件を確認すること**）、学校の座標は国土地理院 住所検索API（地図に「出典：国土地理院」と表示する）

## 個人情報
個人名・個人の連絡先・顔写真は含めていない。根拠URLのページ自体に個人名が載っている場合があるため、サイトでは根拠URLを「出典リンク」として扱い、内容を転載しない。
